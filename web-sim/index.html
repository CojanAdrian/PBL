RoadFix Simulator

A web replica of the SwiftUI app on branch integrate-full-app, with the Swift logic ported line for line. Firebase Auth and Firestore are replaced by an in-browser mock that enforces firestore.rules. The map uses OpenStreetMap in place of Apple Maps. This is not a real iOS build.

Accounts (mock Firebase Auth)

“Fill” types the credentials into the Log In screen. Only staff accounts see the Staff tab.

Conditions

Location (Simulator → Features → Location)

Turn this on to reproduce the bug from the full-app folder. iOS never asks for location and New Report waits forever.

Backend

Leave it empty to delete the doc. Then every staff sign-up falls back to citizen.

Reports (Firestore reports)

    Saved in the mock Firestore. Reports are shared between accounts, survive relaunches, and each user can upvote a report once. Photos go to mock Firebase Storage.
